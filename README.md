# 📌 FocusBoard

**FocusBoard** is a lightweight and modern task management web application designed to help users **organize, track, and complete daily tasks efficiently**.

---

## Features
- **Add Tasks:** Name, priority, category, and due date.
- **Task Management:** Mark tasks as completed, undo completion, or delete tasks.
- **Progress Tracker:** Visual progress bar shows % of tasks completed.
- **Persistent Storage:** Tasks are saved in browser `localStorage`.
- **Clean UI:** Pleasant light design with attractive buttons, cards, and interactive elements.

---

## Technologies
- **Frontend:** React.js, JavaScript, HTML, CSS  
- **State Management:** React `useState`, `useEffect`  
- **Storage:** `localStorage` for persistent task data
